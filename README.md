GitTools-EN

Windows batch toolkit for Git operations.

This project is mainly designed for Windows.
Linux support exists but features are incomplete, some functions may not work properly.

## Usage

1. Make sure Git is installed and added to system PATH.
2. Run the main script.
3. Select Git commands from the menu.

## Notes

- Tested on Windows 10 / Windows 11.
- Linux compatibility is limited, not fully functional.
- This is a script wrapper for native Git commands.

## Requirements

Git
